## My Free Telemetry Viewer
I made this software as an alternative to other free telemetry viewing software. There's a focus on customizability in how you make your layout as well as other settings that can be controlled by the users such as line width and colors in graphs. Still in development, future games will be supporting as well as more tracks added soon!

Download the setup.exe file from the latest release.

After running the installer the program will be installed by default at C:\Users\<username>\AppData\Local\Programs\<App Name>


## 1. Download Lap telemetry

Telemetry can be downloaded from Garage61's website from the search tab by pressing the mall arrow next to analyze and pressing download in CSV format.

## 2. Import CSV files into the app

Select the file dropdown at the top left of the screen and select one or multiple CSV files to import.

## 3. Select a track from the Track Map overlay dropdown

In the top left corner there is an option to access all the maps for the included tracks. Map pool is limited right now with more on the way.

## 4. Organize your layout

Once laps are added you can organize the layout of the app to suit your needs. You can fill each empty pane with the dropdown menu at the top of each pane.
